## 2. The gap that matters most, and it is on no list

0074 §3 **derived** the nonabelian amplitude's multiplicities from
the frame measure and reported the profile as *"peaked, not
monotone"*. Every module from 0091 onward — the entire continuity
front — instead uses **flat counting**, all n_j = 1, described in
0091's own docstring as "flat counting".

> **The weight that was measured is not the weight that was
> derived.**

| multiplicity profile | κ | ξ/a |
|---|---|---|
| **flat (what was simulated)** | **13.337** | **6.4e+14** |
| peaked, mild | 11.336 | 3.2e+12 |
| peaked, strong | 10.403 | 2.7e+11 |
| rising | 16.014 | 8.0e+17 |
| falling | 9.000 | 6.5e+09 |

κ moves by a factor 1.8. But the hierarchy is **exponential** in κ,
so ξ/a runs **6e9 to 8e17 — eight orders of magnitude**, set by a
simplification nobody had priced.

**What survives and what does not.** The continuity front's
*structural* results stand: there is still no dial to tune, asymptotic
freedom still supplies the separation without tuning, and Lorentz
restoration was measured on whatever weight was in fact used. What
does not survive unqualified is **the number**, ξ/a ~ 10¹³ — and with
it the "why gravity is weak" chain, whose whole content was that
number.

## 3. The punch list

1. **Derive the SU(2) amplitude's multiplicities.** 0074 §3 has a
   derivation and a profile; nothing since uses it. Re-derive, then
   re-run the coupling. *The largest single unpriced dependence in
   the program.*
2. **Port or retire the Λ quantisation.** The mechanism is total
   curvature mod N on a closed surface; on SU(2) the analogue is a
   π₁ / centre statement, not a mod-N one. Until it is ported the
   program has **no observational route**.
3. **Find a continuum constraint on the level, or accept there is
   none.** Every level passes the SU(2) tests run so far.
4. **Lift the two-ledger theorem properly.** lucid 0027 gives a
   partial SU(2) form; the full statement is still the Z_N proof.
5. **Re-price the level measurement.** n\* = 58 was computed over the
   ladder.

**Ordering.** (1) is first because it is cheap, self-contained, and
every number downstream of the coupling depends on it. (2) is second
because it is the difference between a theory with a falsifiable line
and one without.

## 4. The honest reading

The toy was doing more work than the boards recorded. That is not a
scandal — it is what an exactly-solvable tier is *for*, and the
program lifted the central objects (the Born square, positivity,
reflection positivity, the interacting measure) deliberately and
early. But three things were carried across as if lifted when they
were not, and one simplification was never priced at all.

The program is not smaller than it was. It is **less finished than
the boards said**, in a way that is now enumerated and mostly cheap
to fix.
